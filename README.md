# 🌐 HTML Portfolio  
### Personal Portfolio Website Using HTML & CSS

A simple and clean **personal portfolio website** built using HTML and CSS to showcase my skills, projects, and basic web development knowledge.

---

## 📌 Overview

The **HTML Portfolio** is a static website designed to represent my profile as a developer.  

It highlights:
- My introduction  
- Skills  
- Projects  
- Contact information
